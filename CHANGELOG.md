# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-25

### Added
- Local web app: OpenStreetMap discovery, website check, lead scoring, demo site and PDF generation, multilingual first messages.
- WhatsApp Web, Instagram and e-mail sending through one dedicated Chrome profile, with daily caps and compliance guards.
- Reply and follow-up tracking, pipeline, analytics and watcher.
- `radar.py --selftest` (42 assertions) and CI workflow.
- `scripts/setup.sh` (venv, requirements, `.env`, self-test, optional `--with-browser`) and `scripts/run.sh`.
- `requirements.txt`, `AI_SETUP.md`, hero image, CONTRIBUTING, SECURITY, issue templates and `.editorconfig`.
